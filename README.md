## 🏙️ О проекте

Омск, глухая ночь. За окном старой лаборатории тихо мерцает огнями телебашня. Перед вами — ламповый радиоприемник и терминал. Из радиоэфира доносятся странные помехи, скрывающие в себе закодированные сигналы. 

Сможете ли вы настроиться на нужную частоту, разгадать входящие передачи и выбраться отсюда? Или подтвердится главная городская легенда?..

## 🎮 Геймплей и особенности

* **Аналоговая настройка радио**: Наведение на тумблеры и плавная регулировка частоты и длины волны колесиком мыши.
* **Световая индикация**: Светодиоды подсказывают совпадение параметров радиосигнала.
* **Мини-игры на мониторе терминала**:
  * 🔐 **Дешифратор кода**: Расшифруйте входящее сообщение, закодированное двоичным представлением алфавита.
  * 🎯 **Перехват импульса**: Динамический кликер на скорость реакции по летающей точке.
  * ⏱️ **QTE-синхронизация**: Точный тайминг и попадание в зеленую зону с нарастающей скоростью.
* **Аутентичный визуал и звук**: Пиксельная графика, процедурные анимации фонов, звуки щелкающих переключателей и клавиш ретро-клавиатуры.

## 🕹️ Управление

| Действие | Управление |
| :--- | :--- |
| **Крутить тумблеры радио** | Навести курсор на тумблер + **Колесико мыши (Scroll)** |
| **Клики в терминале / мини-играх** | **Левая кнопка мыши (ЛКМ)** |
| **Ввод ответов в терминале** | **Клавиатура (русская раскладка)** + **Enter** |
| **Стирание символа** | **Backspace** |
| **Продолжить после расшифровки** | **Пробел (Space)** |
| **Выход из игры в финале** | **Enter** |

## 🛠️ Стек технологий

* **Язык разработки**: Java 21
* **Игровой движок**: [libGDX 1.14.0](https://libgdx.com/)
* **Графический бэкенд**: LWJGL 3 (Desktop, OpenGL)
* **Работа со шрифтами**: `gdx-freetype` (динамический рендеринг кириллического шрифта `KONSTRUKT`)
* **Примитивы**: `space.earlygrey:shapedrawer`
* **Система сборки**: Gradle 9.x Wrapper
