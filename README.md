## 🏙️ О проекте

Омск, глубокая ночь. За окном старой лаборатории монотонно мерцает огнями телебашня. Перед вами — винтажный аналоговый радиоприемник и монохромный монитор терминала. 

Сквозь белый шум радиоэфира пробиваются обрывки загадочных передач. Чтобы поймать сигнал, необходимо точно настроить частоту и длину волны, а затем расшифровать входящее сообщение с помощью компьютерного терминала.

Сможете ли вы перехватить все сигналы и выбраться отсюда? Или подтвердится главная легенда?..

## 🎮 Игровой процесс

Игровой цикл разворачивается в три этапа с нарастающей сложностью:

1. **📻 Настройка радиостанции**:
   * Два поворотных тумблера: настройка **частоты** (Frequency) и **длины волны** (Longitude).
   * Светодиодные индикаторы: красный цвет — поиск волны, зелёный — параметр зафиксирован.
   * При совпадении обоих параметров раздаётся звуковой сигнал подтверждения и активируется терминал.

2. **💻 Мини-игры на мониторе**:
   * 🔐 **Этап 1: Дешифратор сигналов (`CodeDecryptMiniGame`)** — входящие слова закодированы номерами букв русского алфавита в двоичной системе счисления с точечным разделителем (например, `1100.10000.10100` $\rightarrow$ `кот`). Введите расшифрованное слово с клавиатуры.
   * 🎯 **Этап 2: Поимка импульса (`CatchDotMiniGame`)** — поймайте кликами мыши непредсказуемо отскакивающую красную точку 5 раз подряд.
   * ⏱️ **Этап 3: Синхронизация частоты (`ReactionMiniGame`)** — проверьте свою реакцию в QTE-режиме: поймайте движущийся бегунок в зелёной зоне 3 раза подряд. С каждым удачным попаданием скорость возрастает!

3. **👁️ Финал**:
   * По завершении всех этапов тайны радиоэфира раскроются в атмосферной кульминации.

## 🕹️ Управление

| Действие | Управление |
| :--- | :--- |
| **Крутить тумблеры радио** | Навести курсор мыши на тумблер + **Колёсико мыши (Scroll)** |
| **Взаимодействие с терминалом / QTE** | **Левая кнопка мыши (ЛКМ)** |
| **Ввод ответов в дешифраторе** | **Клавиатура (русская раскладка)** |
| **Подтверждение ввода** | Клавиша **Enter** |
| **Стереть символ** | Клавиша **Backspace** |
| **Закрыть сообщение на мониторе** | Клавиша **Space (Пробел)** |
| **Выход в главное меню из финала** | Клавиша **Enter** |

## 🚀 Сборка и запуск

### Требования
* Установленный **JDK 21** или новее.
* Git.

### 1. Клонирование репозитория
```bash
git clone https://github.com/SuperSevenPro55/lost-in-omsk.git
cd lost-in-omsk
```

### 2. Запуск игры через Gradle
* **Linux / macOS**:
  ```bash
  chmod +x gradlew
  ./gradlew lwjgl3:run
  ```
* **Windows (cmd / PowerShell)**:
  ```cmd
  gradlew.bat lwjgl3:run
  ```

### 3. Сборка исполняемого JAR-файла
```bash
# Linux / macOS
./gradlew lwjgl3:jar

# Windows
gradlew.bat lwjgl3:jar
```
Готовый запускаемый `.jar` файл будет сохранён в каталоге `lwjgl3/build/libs/`.

Запуск собранного архива:
```bash
java -jar lwjgl3/build/libs/*.jar
```
